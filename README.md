# MASTER 5 MENIT

**ZBY-BTC Quantitative Terminal — Polymarket Feed Pro + Chainlink TWAP Engine**

Platform trading kuantitatif kontrak 5-menit real-time dengan integrasi:
- **Matrix Kontrak 5-Menit**: Strike Price, TWAP Benchmark, Peluang UP / DOWN, dan Sinyal AI Edge.
- **Grafik Aksi Harga Real-time (Recharts)**: Garis Spot Price vs Garis TWAP Chainlink dengan garis referensi Strike Price.
- **Fractional Kelly Sizing & Execution**: Rekomendasi stake presisi (0.25 Safe dan 0.5 Half Kelly) dan tombol order instan (Buy UP / Buy DOWN).
- **Multi-Theme Contrast Engine**: Dukungan Dark (Institutional), OLED Black, Amber Gold, dan Lite Clean.
- **Konsol Log & Konfigurasi**: Terminal pemantauan order real-time dan parameter orakel.
